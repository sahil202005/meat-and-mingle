# MEAT & MINGLE
Premium single-page non-veg restaurant demo. React + Vite, Tailwind CSS, Framer Motion, Lucide. Frontend only, mock data.

```bash
npm install
npm run dev     # local dev
npm run build   # production build -> dist/
```
Food images load from Unsplash (see `src/data.js`); a gradient fallback shows if one fails.
